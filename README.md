# 国家科技重大专项项目管理系统

基于 Vite + React + TypeScript + Ant Design + Zustand 的国家科技重大专项科研成果管理与项目材料归档系统。

## 功能模块

### 科研成果管理

- **课题配置**：维护课题基础信息、参与单位、课题总体成果要求（5 种成果类型）、国内期刊论文要求、电网公司主导成果要求
- **时间节点配置**：管理项目交付节点（年度/中期/试运行/结项等），支持排序和预警开关
- **指标分解**：按课题、时间节点将各类成果指标分解至参与单位，矩阵式录入，自动汇总与缺口提示
- **预警规则配置**：5 种预警类型（时间/数量缺口/进度/佐证材料/国内期刊比例），黄/橙/红三级阈值可自由配置
- **成果录入**：按 5 种成果类型动态表单，支持认定类型选择（论文录用/刊出、专利受理/授权等），保存草稿与提交审批差异化校验，状态锁定机制
- **成果审批**：系统自动校验成果认定条件、佐证材料完整性，支持审批通过/退回修改/审批不通过
- **指标监控**：项目/课题/单位/节点多视角切换，完成率与缺口实时计算，Excel 导出，预警中心集中展示

### 项目材料归档

- **归档目录**：维护归档分类目录及必交材料清单
- **材料上传**：支持从科研成果同步或独立上传，文件版本管理
- **材料查询**：按目录/名称/上传人筛选
- **归档监控**：基于必交清单计算归档完整率，支持按节点筛选

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

## 脚本

```bash
npm run dev      # 开发服务器
npm run build    # 生产构建
npm run lint     # 代码检查
npm run test     # 运行单元测试（Vitest）
```

## 使用说明

1. 左侧菜单切换功能模块，所有功能为统一工作台，无角色区分
2. 科研指标配置包含「课题配置」「时间节点配置」「指标分解」三个页签
3. 成果录入支持保存草稿和提交审批，提交后锁定不可编辑
4. 点击「重置演示数据」可恢复初始 Mock 数据
5. 首次打开使用 localStorage 持久化数据（key: `research-achievement-storage-v5`）

## 技术栈

- 前端框架：React 19 + TypeScript
- 构建工具：Vite 8
- UI 组件库：Ant Design 6
- 状态管理：Zustand（localStorage 持久化）
- 日期处理：dayjs
- 路由：React Router 7
- Excel 导出：xlsx
- 测试框架：Vitest
