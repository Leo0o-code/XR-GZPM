# 国重项目 · 科研成果管理

基于 Vite + React + TypeScript + Ant Design + Zustand 的科研成果管理演示系统。

## 功能模块

- 指标配置：按课题、成果类型、考核节点配置计划数量、截止日期、认定状态、佐证材料、预警规则等。
- 批量配置：一次性为 5 个课题配置同一成果类型指标。
- 分批交付节点：配置阶段性交付节点，避免成果集中突击完成。
- 我国科技期刊论文配置：设置总数、最低数量/占比、整体考核或分解至课题、期刊名录版本。
- 配置发布机制：草稿 → 已发布 → 已调整 → 已停用，自动记录版本变更。
- 完成统计：计划数量、已登记、进度达标、材料提交/通过、已认定、尚缺、完成率。
- 预警中心：时间预警、数量缺口、进度不足、佐证材料、中国科技期刊比例、未分解指标。
- 预警规则：黄/橙/红三级阈值可配置。
- 期刊名录管理：维护我国科技期刊名单。
- 指标监控：管理员查看各课题实际完成和缺口。
- 课题端看板：各课题查看自己的交付要求、缺口、最近节点、状态，并下钻到具体成果和材料。

## 快速开始

确保已安装 Node.js（推荐 18+），本机已使用 Node 22.22.2 验证。

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 打开浏览器访问 http://localhost:5173
```

## 构建生产版本

```bash
npm run build
```

## 使用说明

1. 页面顶部可切换“管理员”和“课题端”身份。
2. 管理员通过左侧菜单访问各配置和监控页面。
3. 课题端选择课题后查看本课题看板，点击“下钻”查看成果明细。
4. 点击“重置演示数据”可恢复初始 Mock 数据。

## 技术栈

- 前端框架：React 19 + TypeScript
- 构建工具：Vite 8
- UI 组件库：Ant Design 6
- 状态管理：Zustand（持久化到 localStorage）
- 日期处理：dayjs
- 路由：React Router 7
